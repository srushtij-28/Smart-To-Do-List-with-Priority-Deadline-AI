# 📋 Smart To-Do List with Priority & Deadline AI 

## 💡 Overview
The **Smart To-Do List** is an intelligent task manager built with Python.  
Unlike a normal to-do list, this app automatically calculates an **urgency score** for every task based on its **deadline and priority**, helping you decide what to work on first.

It works like a **mini productivity AI** that ranks tasks in the smartest possible order.

---

## 🚀 Features

### ➕ Add Tasks
- Add tasks with:
  - Task name  
  - Due date  
  - Priority (1–5)

### 🧠 Smart Priority Engine
- Calculates urgency based on:
  - Days left until deadline  
  - User-assigned priority  
- Automatically ranks tasks

### 📋 Intelligent Task List
- Displays tasks sorted by urgency  
- Shows what you should work on first  

### 🌐 Fully Offline
- No APIs  
- No internet  
- Runs completely in the terminal
